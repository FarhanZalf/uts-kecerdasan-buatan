Dataset yang digunakan dalam penelitian ini adalah Iris Dataset yang diperoleh dari repositori resmi UCI Machine Learning Repository . Dataset ini diperkenalkan oleh biolog dan statistikawan Ronald A. Fisher pada tahun 1936 dan menjadi salah satu dataset benchmark paling terkenal dalam dunia machine learning.

⚙️ Preprocessing & Pembagian Data (Split)

  • 1. Pembersihan Data (Data Cleaning): Dataset asli diverifikasi bebas dari baris kosong (blank lines) dan spasi berlebih pada label kelas.
  • 2. Pembagian Train-Test Split (80% : 20%): Data dibagi menjadi 120 sampel data training untuk pembentukan model pohon keputusan dan 30 sampel data testing untuk pengujian evaluasi.
  • 3. Stratified Sampling: Pembagian data menggunakan parameter stratify=y sehingga komposisi kelas pada data testing tetap seimbang (10 Setosa, 10 Versicolor, 10 Virginica).
  • 4. Validasi Silang (10-Fold Cross-Validation): Sebagai pembanding dengan artikel jurnal referensi, kami juga menerapkan 10-Fold Cross-Validation untuk menjamin model tidak mengalami overfitting.
